# 产品视觉一致性系统

## 目标

把产品“像不像实物”的判断从主观描述变成固定的人工验收。适用于所有包含完整酒瓶、酒标、木质礼盒或白色外包装的成图、视频首尾帧与电商资产。

## 参考图角色

每个产品画面只选 2–3 张参考图，并登记以下角色：

| 角色 | 用途 | 当前固定母版 |
| --- | --- | --- |
| `geometry_master` | 完整酒瓶比例 | `酒瓶-正面.png` |
| `dimension_check` | 各高度投影宽度、纵向分段与瓶身曲线校准 | `尺寸示意图.png` |
| `structure_master` | 礼盒、合页、开合角度 | 正面开盒用 `木质礼盒-内置酒瓶.png`；半开用对应半开图 |
| `label_detail` | 仅校准酒标文字、边界、贴附位置与玻璃曲面关系 | `酒瓶-酒标.png` |
| `style_anchor` | 光线、木纹和氛围 | 依据当前内容选择 |

冲突时必须遵循：`geometry_master > structure_master > label_detail > style_anchor`；`dimension_check` 是独立的生成前/后验收层，不替换上述身份与结构角色。**酒瓶-酒标.png严禁单独承担整瓶几何校准**：它不能决定瓶盖到酒肩、酒肩到瓶底、瓶身宽高或整体透视。含酒标的整瓶画面必须同时调用 `酒瓶-正面.png`（整瓶几何）、`尺寸示意图.png`（分段尺寸）和至少一张其他角度酒瓶图（立体曲线），再用 `酒瓶-酒标.png` 校准酒标局部。

## 人工验收卡

完整酒瓶至少核对：

- 瓶盖、瓶颈、瓶肩、瓶身与瓶底的纵向比例；
- 使用 `尺寸示意图.png` 复核瓶盖、颈部、肩部过渡、最大肩宽、标签区、底部过渡与瓶底宽度的连续曲线；
- 玻璃底座厚度、酒液高度和酒标位置；
- 瓶身不得横向压扁、拉长、截断或出现第二套标签；
- 暗背景中的边缘必须是自然折射与接触阴影，不得有白边、灰边或抠图光晕。

### 分段比例复核（生成后必做）

将酒瓶按“瓶盖/瓶颈/颈肩过渡/酒肩至瓶底/瓶底厚度”分段，与 `尺寸示意图.png` 的纵向基准逐段对照。重点检查：

1. 酒盖到酒肩的总段不能被压短；透明瓶颈、金色包纸和酒液顶端的相对位置必须连续。
2. 酒肩到瓶底主体段不能矮胖；若肩部以下明显短于正面母版，直接判定 `rejected`。
3. 最大肩宽、标签区宽度、底部过渡和瓶底外径的相对顺序必须保持；不能只看标签“像不像”。
4. 任何新增瓶身印字、浮雕、数字、徽章、第二套标签或镜像文字，均判定 `rejected`。

### 两阶段核准

- **阶段A：结构核准**：先隐藏/忽略传播文字，只看产品轮廓、分段比例、液面、标签贴附和礼盒结构。
- **阶段B：传播核准**：再检查背景融合、文字洁净度、可读性和主体安全区。阶段B不得通过缩放、裁切或加边掩盖阶段A问题。

木质礼盒至少核对：

- 正面开盒固定为175°–180°；半开画面按对应半开参考图，不得假装完全展开；
- 左侧白色内皮、故事文字、中央合页、右侧瓶槽必须与参考结构一致；背面/侧面 AIGC 场景必须以对应产品原图锁定铰链位置和结构，但不得直接把原图作为成片底图；从背面视角看，铰链应位于右侧窄侧板更靠画面深处、靠近正面门板的远侧外边，不能贴近可见背板接缝；模型只能改变环境、光线和景深，不得重新推断这一空间关系；
- 礼盒与内置酒瓶不能分别拉伸，必须保持整体比例。

## 文字洁净度

传播文字使用多模态模型一次成图，但必须额外验收：

- 逐字匹配 `Text (verbatim)`；
- 字内无波纹、摩尔纹、颗粒、木纹、液化或不均匀反光；
- 英文固定词组不得拆词或改拼写；
- 360px 宽手机预览下，主标题可在 1–2 秒读清；
- 产品正确而文字不合格时，只重绘文字安全区，不重新生成产品主体。

## 退回规则

任一关键比例、开盒结构、文字洁净度或产品边缘融合不通过，资产状态写为 `rejected`，不得进入 `release-manifest.json` 的 `publish` 列表。
