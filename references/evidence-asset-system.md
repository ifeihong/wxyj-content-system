# 真实证据资产系统

## 原则

AIGC 高清产品参考图负责产品身份、结构和高奢氛围；真实实物、酒标和授权/进口文件负责信任。两类资产不能互相替代。

## 建议资产池

在品牌私有素材库中分别维护：

| 资产类型 | 用途 |
| --- | --- |
| 实物酒瓶与酒标原图 | 产品身份、细节与酒标字段 |
| 礼盒与开箱实拍 | 包装、礼赠与开盒内容 |
| 进口、报关、溯源、授权文件 | 合法经营与来源说明 |
| 品鉴会与店铺真实素材 | 活动或转化内容 |

每项真实素材登记来源、日期、可公开范围和对应产品。未取得公开授权的文件只作为内部核验，不直接发布。

## 选题使用规则

- 氛围、节日、风味转译：AIGC 产品图可以承担主画面；
- 来源、正品、进口、标签字段、授权、线下活动：优先使用对应真实证据；
- 没有真实证据时，将内容改为产品表达或主观品鉴，不把 AIGC 画面写成实拍证明。

## 发布前

在 `sources.md` 标明每条关键事实的证据来源与公开状态；在 `release-manifest.json` 的 `evidence` 门槛中记录 `pass`、`pending` 或 `not-applicable`。公开文案不展示内部核验过程或 AIGC 说明。
