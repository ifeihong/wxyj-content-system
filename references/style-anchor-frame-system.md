# 视频风格锚点帧锁定系统

## 目的

当一条视频同时包含 Seedance 动态素材和 ChatCut 静态镜头时，先锁定一套符合当次画幅的“镜头定稿图”（默认原生9:16，明确要求时3:4），再让所有镜头共享同一视觉语言，避免动态镜头与静态镜头像来自不同作品。

## 正确分层

| 层级 | 负责内容 | 优先级 |
| --- | --- | --- |
| `geometry_master` | 酒瓶、酒标、瓶盖、瓶肩、瓶腹、瓶底比例 | 最高 |
| `structure_master` | 木盒开合角度、合页、内衬、内页与酒瓶相对位置 | 次高 |
| `dimension_check` | 各高度投影宽度、曲线和纵向比例 | 几何复核 |
| `style_anchor` | 色彩、光线、材质、景深、颗粒、镜头高度和设计语法 | 风格层 |
| `shot_keyframe` | 当前镜头最终构图、主体位置和留白 | 生成入口 |

风格锚点帧不能覆盖产品几何。产品原图和尺寸示意图始终优先于风格锚点帧。

## 每条视频的标准流程

1. 先登记一张共享 `style-anchor.md`：色温、主光方向、背景材质、镜头高度、景深、颗粒、产品占比和字幕安全区。
2. 为每个镜头先生成一张当次画幅 `shot-keyframe`，统一使用共享风格锚点；每张只改变镜头职责、机位和主体构图。
3. 对每张 keyframe 做产品视觉QA：瓶型、瓶肩到底部比例、酒标位置、木盒角度、边缘融合、主体完整边界。
4. Seedance镜头使用对应 `shot-keyframe` 作为 `first_frame` 或首要参考图，再加入必要的 `geometry_master` / `structure_master` / `dimension_check`。
5. 静态镜头直接使用对应 `shot-keyframe`，在ChatCut中做一条连续推拉或横移曲线，不拆成多张裁切图。
6. 所有字幕、事实数字、时间线、转场线条和旁白同步在ChatCut完成；Seedance素材和keyframe不得预生成这些后期元素。
7. 先验收S01，再批量生成其他Seedance镜头；风格漂移时只修风格变量，不同时改产品几何和叙事。

## 共享风格锁定字段

```yaml
style_id: walnut-amber-editorial-v01
palette: 深胡桃木、深棕近黑、琥珀酒液、香槟金高光
key_light: 左后方暖金轮廓光
fill: 低强度暖棕环境光
camera_height: 与酒瓶标签中心略低的平视高度
lens_language: 轻微长焦压缩、浅景深、克制运动
texture: 细腻木纹、自然玻璃反射、低颗粒
safe_text_zone: 不覆盖酒标、瓶盖、内页正文和礼盒铭牌
```

## 退回条件

- 同一视频不同镜头色温、主光方向或背景材质明显跳变；
- keyframe中产品比例正确，但Seedance运动后出现瓶肩、瓶底或酒标漂移；
- 静态镜头使用了与动态镜头不匹配的白底棚拍风格；
- 用风格参考图替代酒瓶几何母版；
- 通过把一张图拆成多个裁切片段伪造连续运动。
