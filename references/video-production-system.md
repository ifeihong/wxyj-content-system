# 三平台竖屏视频生产系统

## 目录

1. 适用范围与默认生产路径
2. 四种制作模式与工具路由
3. 原生竖屏、镜头与产品规则
4. 文字、运动和声音
5. 平台母版与 QA

## 适用范围

用于威熏邑境抖音与视频号的共同视频母版。目标是高品质、时尚、大气、高奢，同时保持产品身份、酒标事实和成本可控。两个平台共用一个 `video-master/`，分别保留发布文案与平台 CTA。

## 默认生产路径

```text
生成共享video-master
→ 选择视频制作模式
→ 为external-seedance镜头创建逐镜任务包
→ 等待用户回传
→ 验收incoming
→ 把accepted素材进入可编辑剪辑
→ 输出抖音与视频号发布包
```

默认由 Codex 选择参考图、编写任务卡和提示词；用户只在任意支持相应输入模式的平台生成并回传。默认不消耗 ChatCut 视频生成积分。

## 四种制作模式

| 模式 | 名称 | 适用内容 | 主要工具 |
| --- | --- | --- | --- |
| V1 | 混合高奢短片 | 产品发布、日期故事、核心品牌片 | 外部 Seedance + 可编辑剪辑 |
| V2 | 生成式电影感 | 氛围、风味、时间隐喻 | 外部 Seedance |
| V3 | 编辑型动态图形 | 酒标解读、数字证据、知识解释 | HyperFrames 或 Remotion |
| V4 | 受控静帧蒙太奇 | 证据、文件、包装细节、低预算日更 | 原生9:16静帧 + 可编辑时间线 |

日常默认使用 V1：关键产品镜头交给外部 Seedance，事实数字和长文字交给可编辑动态图形，证据镜头使用真实素材或经过 QA 的静帧。

## 工具路由

- 外部 Seedance：图生视频、首帧、首尾帧、多参考运动；由用户在第三方平台生成。
- HyperFrames：信息图形、章节标题、数据卡、可控排版。
- Remotion：程序化动画、精确时间、字幕、数字与版本化导出。
- ChatCut：素材管理、可编辑剪辑、字幕、声音、动态图形和导出。
- ChatCut 付费生成：只有用户在当前任务中当次明确授权后才能使用。

不得因为回传镜头失败而静默切换到付费生成，也不得把本地扁平 MP4 代替用户要求的可编辑项目。

## 原生竖屏硬门槛

- 所有全屏视频、运动首帧、尾帧和封面均为原生9:16。
- 成片基准为 `1080×1920`；草稿最低为 `720×1280`。
- 3:4图片不能作为全屏主画面；如需复用，只能进入经过设计的画中画、卡片或局部裁切模块。
- 禁止黑边、灰边、上下留黑、简单补边和整屏拉伸。
- 不允许先做3:4再扩图为9:16；首轮就按9:16构图。
- 回传视频必须通过 `validate_external_video_return.py` 的画幅、时长、文件名和解码检查。

## 镜头多样性

同一条短片不要连续使用相同正面机位。建议顺序：

1. 日期或酒标局部；
2. 左/右45°完整酒瓶；
3. 木质礼盒或包装结构；
4. 证据数字动态图形；
5. 风味氛围或收束镜头。

完整正面酒瓶只在必要镜头出现；不得靠模型从单张正面参考推演大角度旋转。需要角度变化时使用对应角度参考或严格首尾帧。

## 产品身份与边缘

- `geometry_master` 优先于风格参考；瓶盖、瓶颈、瓶肩、瓶腹、玻璃底和标签位置不得漂移。
- 白底产品图只用于身份与几何，不直接作为运动首帧。
- 先制作原生9:16运动首帧，重建玻璃折射、环境色、接触阴影和外缘反射。
- 禁止白边、灰边、抠图光晕和一圈均匀描边。
- 酒标微小文字、瓶号和日期不交给视频模型重绘；由通过 QA 的首帧保留或用时间轴图形准确呈现。

## 文字设计

- 片头标题、章节卡和封面可以在静帧生成阶段直接生成设计文字。
- 连续字幕、事实数字和长文使用可编辑时间轴文字。
- 高奢排版使用尺度反差、留白、错落层级、细线、局部纵排或中英组合，不使用每镜同一居中模板。
- 文字不得遮挡酒瓶、酒标、礼盒铭牌或证据字段。
- 所有上屏事实逐字核对产品事实库。

## 运动和声音

- 产品本体低运动，优先运动镜头、灯光、背景粒子与景深。
- 推拉和环绕要克制，避免液面跳变、瓶身呼吸和标签游移。
- 转场由材质、光线、遮挡或图形逻辑驱动，不堆叠炫技插件。
- 声音采用低频质感、木盒开合、玻璃轻触、纸张与环境氛围；旁白优先清晰可信。
- 音乐不得掩盖旁白，也不得暗示豪饮、未成年人或驾驶场景。

## 平台母版

抖音与视频号使用同一视频母版和镜头资产：

- 抖音重写3秒钩子、标题、简介、置顶评论和话题；
- 视频号重写5秒观看理由、描述、首评、朋友圈转发文案和话题；
- 两个平台不得复制同一完整开头和 CTA；
- 平台目录不复制 `storyboard.md` 或同一成片源文件。

## QA门槛

发布前逐镜检查：

1. 精确9:16、无黑边、无3:4直接补边；
2. 瓶型、标签、液面、礼盒结构连续；
3. 产品边缘已融入新环境；
4. 日期、年份、酒龄、桶号、酒精度、容量与瓶数口径准确；
5. 动态文字完整、可读、不挡主体；
6. AIGC和真实证据边界清楚；
7. `incoming` 原件保留，只有通过项进入 `accepted`；
8. 同一问题连续两次失败后停止继续抽卡并出修订卡。
