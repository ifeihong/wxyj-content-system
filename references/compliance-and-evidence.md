# 证据与合规

## 证据等级

| 等级 | 内容 | 可支持的表述 |
| --- | --- | --- |
| A | 进口、装瓶、授权文件，原始酒标或包装原文，官方书面资料，经营方确认的逐字转录 | 产品身份、日期、桶号、包装载明信息、法定主体 |
| B | 真实酒瓶、包装、库存、发货、真实活动记录 | 外观、实际存在、活动事实 |
| C | 经确认的内部品鉴记录 | 主观香气、口感、尾韵 |
| D | AIGC 场景、解释图、动画 | 氛围、隐喻、知识解释 |

A/B 级支持事实；C 级必须标为主观体验；D 级不能证明产品来源、历史、酒厂或真实使用场景。

经营方确认的酒标或包装转录可以进入事实库；若画面本身是 AIGC，发布时不要称其为“实拍证据”。历史、人物和机构信息优先表述为“礼盒内页记载”或“品牌包装资料介绍”。

## AIGC 标注

在制作清单中逐镜或逐页写明：

- `真实`：实拍或真实文件；
- `AIGC`：生成画面、动画或氛围；
- `待补`：发布前补拍或核验。

允许：

> AIGC 时间流逝动画 + 真实酒标局部。

不允许：

> 1996 年真实入桶现场（实际为生成画面）。

如果面向消费者的成片容易让人误认为真实历史画面，在画面或正文中加入“创意演绎/AIGC 画面”。

## 一票否决

- 未成年人饮酒或以年轻化形象吸引未成年人；
- 豪饮、拼酒、酒驾或以酒量证明身份；
- 医疗、助眠、养生、治疗或健康功效；
- 保值、升值、稳赚、投资回报；
- 虚构酒厂关系、专家、奖项、评分、销量、库存、顾客反馈；
- AIGC 冒充真实酒厂、人物、历史现场、品鉴或顾客；
- 无证据的“全球唯一、最好、最顶级、官方、绝版”；
- 与实时库存、价格、店铺、活动不一致的紧迫感。

## 高风险表达替换

| 高风险 | 可核验替换 |
| --- | --- |
| 全球仅剩 184 瓶 | 该桶总装瓶数为 184 瓶 |
| 买了只会升值 | 是否购买应基于饮用、礼赠或个人偏好，不作投资承诺 |
| 顶级雪莉桶 | 酒标标示为 PX Sherry Hogshead；不要由此推导“顶级、稀有、初填”等结论 |
| 所有人都能喝出黑樱桃 | 我们的品鉴记录更接近黑樱桃果脯 |
| 情人节专属酒 | 入桶与装瓶日期均为 2 月 14 日 |
| 最后一瓶，错过不再 | 以发布当日真实库存和店铺信息为准 |

## 内容末端提示

按内容需要选用，不机械堆叠：

- 理性饮酒，未成年人请勿饮酒。
- 品鉴感受具有主观性。
- AIGC 画面用于创意演绎，产品信息以实物与文件为准。
- 库存与价格以发布当日店铺或客服信息为准。
