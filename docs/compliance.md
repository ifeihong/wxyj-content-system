# 内容合规与事实边界

## 事实优先级

1. 进口、装瓶、授权和官方书面文件；
2. 实物酒标、包装和真实产品实拍；
3. 经确认的内部品鉴记录；
4. AIGC视觉与解释性画面。

AIGC不能证明产品来源、历史、库存、真实活动或顾客反馈。

## 发布前复核

- 产品名、年份、日期、桶号、酒精度、容量和总装瓶数；
- 当前价格、库存、店铺与活动信息；
- 图片中的酒标、瓶号和包装细节；
- 进口、授权和溯源文件的公开范围；
- AIGC内部来源记录与平台后台AI标签状态；
- 平台最新规则。

## 禁止表达

- 金融收益或价格保证；
- 无依据的最好、唯一、官方、绝版等绝对表述；
- 虚构当前库存、倒计时或抢购紧迫；
- 医疗、健康或功效承诺；
- 未成年人饮酒、豪饮、拼酒或酒驾暗示；
- 把AIGC说成真实酒厂、历史现场或顾客评价。

## 酒类内容

- 不面向未成年人；
- 不鼓励过量饮酒；
- 不把饮酒塑造成能力、身份或关系证明；
- 不将酒类商业推广与军事纪念等敏感节点绑定；
- 保留“理性饮酒，未成年人请勿饮酒”等适用提示。

## AIGC记录与平台标签

素材来源、生成方式和事实核验写入内部 `sources.md` 与 `qa.md`。成片、成图、标题、正文、评论和CTA不出现“AIGC创意演绎”“产品信息以实物与文件为准”等内部说明。平台后台要求AI标签时，只使用平台原生开关；平台标签不能替代事实核验。
