# 内容交付契约

## 总则

一套可发布内容由“发布文案 + 生产资产 + 媒体 + QA”组成。只有图片、只有提示词或只有文案都不是完整交付。

## 小红书

### `publish.md`

- 主标题；
- 备选标题；
- 一句话钩子；
- 完整发布正文；
- 5–10个聚焦话题标签；
- 首评；
- CTA；
- AIGC与事实披露。

### `prompts.md`

- 动态页数及依据；
- 套图视觉母版；
- 每页角色与文字密度；
- 每页精确成图文字；
- 每页完整提示词；
- 每页负面提示词；
- 参考图文件与职责；
- 产品保护区；
- 局部重绘规则；
- 单页与套图 QA。

### `media/`

- 已包含设计文字的最终图片；
- QA缩略总览；
- 旧版本保留，不覆盖。

## 抖音

### `publish.md`

- 主标题与备选标题；
- 3秒钩子；
- 视频简介；
- 5–8个相关Tag；
- 置顶评论；
- CTA；
- AIGC与事实披露。

### `video-master/storyboard.md`

- 时间码；
- 逐镜画面；
- 旁白；
- 字幕；
- 音效与节奏；
- 每镜真实/AIGC/待补标记；
- 参考图与视频生成提示词。

### 外部生成与回传

- 所有全屏镜头、首帧、尾帧和封面均为原生9:16；
- 抖音与视频号共用 `video-master/storyboard.md` 和成片母版；
- `video-master/external-generation/` 保存平台无关逐镜任务包；
- 每镜同时提供 `prompt-all-in-one.txt`、`prompt-positive.txt` 和 `prompt-negative.txt`；
- 用户回传原件进入 `video-master/incoming/`，不覆盖、不移动；
- 机器与人工 QA 通过的副本进入 `video-master/accepted/`；
- ChatCut 付费生成只有在当前任务明确授权后才可使用。

## 视频号

### `publish.md`

- 主标题与备选标题；
- 5秒观看理由；
- 视频描述；
- 3–6个相关Tag；
- 首评；
- 朋友圈转发文案；
- CTA；
- AIGC与事实披露。

### `video-master/storyboard.md`

包含完整叙事、逐镜画面、旁白、字幕、素材属性、封面与生成提示词。

## 标题、正文与Tag匹配

- 标题提出的问题必须在正文中得到回答；
- 正文事实必须与画面和酒标一致；
- Tag只能描述真实品类、细分领域、内容意图和品牌；
- 热点Tag必须实时核验且与产品存在直接关系；
- 首评提供补充信息、选择题或下一篇投票，不重复正文；
- CTA优先评论、收藏、分享和关注，再根据阶段承接私信或购买。

## 完成定义

满足以下条件才能标记为可发布：

- 事实可核验；
- 平台字段完整；
- 媒体与文字匹配；
- 文字无错字或乱码；
- AIGC披露明确；
- QA达到80分；
- 目录校验器退出码为0；
- 实时库存、价格和活动信息已人工复核。
