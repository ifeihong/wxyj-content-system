# v2.5.0 与 v2.6.0 升级实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development and execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把近期反复确认的生产要求升级为可生成、可验证、可追溯的运行包契约，并增加长期内容防重复与高奢版式路由。

**Architecture:** v2.5.0 在每个内容运行包中加入机器可读的发布清单、产品视觉人工验收卡、最终交付索引和视频连续运动计划，并由统一预检脚本验证。v2.6.0 在此基础上加入逐条创意指纹、历史台账和多样性校验器，将版式路线、事实、机位、钩子与 CTA 纳入发布前检查。

**Tech Stack:** Python 3 标准库、JSON、CSV、Markdown、unittest；媒体尺寸使用现有图片解析方式，视频元数据沿用 ffprobe 可用性边界。

## Global Constraints

- 小红书首轮成图必须原生精确 3:4；视频全屏素材必须原生 9:16，成片目标 1080×1920。
- 完整酒瓶、酒标、开盒结构与故事内页必须经过人工产品视觉验收；脚本不得声称自动判断审美或产品几何。
- V4 静帧视频一张图片对应一个连续运动镜头，不得用多张静态裁切模拟运动。
- 已有内容包不被覆盖；所有新文件沿用非破坏式创建。
- 公开内容不出现账号名、WXYJ、续集预告或内部 AIGC/事实核验说明。
- v2.5.0 通过独立验收后，才进入 v2.6.0。
