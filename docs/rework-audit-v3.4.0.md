# 全历史返工复盘与 v3.4.0 升级

审阅范围：本对话从8月内容、七夕、电商长图/缩略图、处暑、UGC直到9月图文与混合视频的可见返工反馈，以及当前仓库规则、模板和校验脚本。不是仅针对最近一套重复镜头，也不是重新观看所有历史成片。本次不改历史已确认图片、原始回传视频或23张产品参考图。

## 根因判断

问题不是“再加一句严格保持一致”。主要是四类断层：参考职责/比例口径冲突；单镜好看却没有全片设计；修改没有同步到真正使用的资产和时间线；参数/登记检查代替了实际观看与试听。继续堆叠绝对规则会进一步冲突，例如既要求永远放大，又要求固定原尺寸。

## 历史问题到修正的对应

| 历史返工 | 原因或已核实的规则缺口 | 本次落地 |
| --- | --- | --- |
| 颈肩过短/过长、瓶身矮胖、液面到金边不对、瓶底消失 | 酒标局部母版越权；肩部定义不一；估算尺寸当实测 | 完整正面+尺寸辅助+对应角度，标签只局部；同透视归一化关键点与同尺度对照；不可见不判通过 |
| 礼盒压扁、瓶盒各自缩放、开合超180°、故事页丢字 | 局部正确替代组合比例；全开规则错误套半开 | 整体等比，按具体结构母版；全开/半开分开；保留内页与签名布局 |
| 背面铰链反复放错 | 只描述画面左右，没有门板与背板的三维关系 | 保留“铰链靠正面门板远侧”约束，修图后仍检查真实机位，不靠文件名判断 |
| 酒肩新增1861等印字、酒标丢失 | 模型补全陌生细节；“无文字”误伤原有标识 | 禁新增印字/浮雕/标志，保留既有产品文字；外部片段逐帧抽查，不承诺提示词可绝对锁瓶型 |
| 白灰边、锯齿、玻璃不融背景 | 冻结白底轮廓或粗糙合成 | 锁几何不锁背景像素；原尺寸及200%边缘检查，重建环境反射，不靠全局模糊掩盖 |
| 文字波纹、英文不清晰、太规整/太可爱 | 装饰材质进入字内；风格模板替代阅读层级 | 产品QA与文字QA分开；只修文字区；图文直接生成设计文字，视频字幕模式按当次确认 |
| 每套8页、每页都像封面、桶号/日期/品鉴反复出现 | 页数和事实模板固定；只查标题不查信息增量 | 保留动态页数和单封面；选题先查台账，分别记录问题、钩子、主事实和视觉方式；标签上自然存在不等于需要再讲 |
| 节日只在开头提、幽默开头后面又变参数广告 | 钩子没有在故事中兑现 | 先写事件和结尾兑现，再拆镜头；不得靠无关风味页/背标页凑多样性 |
| 5镜实际只有2类，Seedance与静态各自为政 | 只查相邻view_id；先选素材后写故事 | 全片逐对查部位/机位/景别/信息，相邻查产品状态、光向和语义承接，必须接触表人工审核 |
| 缺Seedance首帧、TXT没文件名/时长、混入时间线设计 | 任务卡只写原则，责任边界模糊 | Agent实际产图；任务卡/正负TXT/合并TXT都有版本记录；首帧槽与辅助参考分开；生成和剪辑时长分开，允许显式减速 |
| 音画错位、结尾没说完、停顿突兀 | 按预估字数排时，改分镜没重排旁白 | 逐镜画面依据与旁白绑定；确认后配音，以实得时长排镜；逐句尾字试听 |
| 推近一开始跳大、中途停止、转场/延时重置 | 动画预设时长和镜头不一致；拆片或两套时钟 | 首可见到尾可见单曲线，包含转场与片尾；抽查25/50/75%及边界，不只检查起止参数 |
| 音乐开头听不见、后段盖旁白、两首叠响、尾1.5秒升音量 | 全程duck、素材自带音乐、尾段独立增益/解除duck | 单一主音乐轨；先单轨后合听；不固定0dB；尾部沿用相同增益包络与素材，检查最后3秒 |
| 字幕有无/位置/大小反复更改后又套旧方案 | 历史偏好被当作永恒指令 | 当次约定优先，明确none/解说字幕/花字，静止/推拉、3:4/9:16同理 |
| “改好了”但ChatCut是旧项目、输出没变化 | 修改登记与实际编辑对象分离 | 核对project/asset/shot ID，回读并导出最新文件；真实抽帧/试听后才说生效 |
| 文件过期、多个最终图、README版本不一 | 多处手改、缺唯一交付清单 | production-plan revision+哈希锁交付文件；VERSION单一版本源；草稿/可交接/成片发布分层 |
| 期望更多曝光，3篇数据就固化结论 | 样本不足、变量混杂 | 保留少于10条可比成熟样本仅作假设；每条一个实验变量，不承诺爆款或因果提升 |

## 可验证的脚本修复

- 旧运动校验误拒绝pull-out/pan，却可接受hold倍率变化及未知运动名；新增回归用例先复现，再分别校验方向与倍率。
- 旧Agent图片校验固定要求静态和Seedance两目录都有图且必须1080×1920；现在优先读取本次production-plan实际镜头与画幅，支持用户指定3:4及纯静帧方案，不把旧候选全部当交付文件。
- 新增production-plan交接校验：缺图、图片尺寸错误、重复文件、全片相同视觉指纹、缺几何参考、状态跳变无说明、文件哈希/审阅revision过期、缺任务文档、重复JSON键均报错。可显式登记减速后使用时长，不循环素材凑秒数。
- 新运行包release schema升级5并创建生产计划草稿；旧包不自动改文件或伪造新审阅。发布预检增加新包ready门槛，混合模式的v2运动计划也纳入检查。
- 版本此前README/创建器3.3.0、VERSION/项目元数据3.2.0、版本文档3.1.0；本次统一3.4.0，创建器读取VERSION。

## 验收范围与不作的承诺

脚本检查的是结构、文件、尺寸与证据登记，不是视觉识别器或音频审美模型。哈希一致不代表文案正确，pass字段也不能代替人工看图。产品比例、故事连贯、高奢排版、音乐和旁白清晰度仍需打开实际媒体检查并写具体观察。

本次没有重新生成历史资产，没有执行ChatCut编辑，也没有把过去的用户确认升级为新版本通过。已安装目录可能落后于仓库；同步需明确目标和验证，不把本地修改冒充GitHub推送。所有既有产品知识与23张参考图保留。

后续每次生产先读主Skill的当次约定，再按媒介路由。新内容先完成全片/全套策划，再生图和任务卡；返工时先定位失败层，只修改受影响资产及其依赖，最终用同一版本的媒体重新验收。
